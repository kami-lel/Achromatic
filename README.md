# Achromatic README

## Controls

#### Exploration Play

Keyboard:

- `W`: Jump
- `S`: Crouch
- `A/D`: Movement
- `Space`: Item Interaction

Controller:

- Left Stick **Up**: Jump
- Left Stick **Down**: Crouch
- Left Stick **Left/Right**: Movement
- Right Trigger: Item Interaction

#### Rhythmic Play

Keyboard:

- holding `W`: Jump
- holding `S`: Crouch
- holding `D`: Dash
- `Space`: Trigger Note

Controller:

- Left Stick **Up**: Jump
- Left Stick **Down**: Crouch
- Left Stick **Right**: Dash
- Right Trigger: Trigger Note
